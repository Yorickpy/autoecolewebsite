# Grenade Auto-Ecole

Site vitrine imagine et developpe pour Grenade Auto-Ecole.

Le projet met en avant l'auto-ecole avec une direction visuelle moderne, une landing page plus vivante, une presentation claire des formations, une page avis, une page contact avec carte integree, et plusieurs details d'interface travailles pour donner une vraie identite au site.

## Apercu

- landing page immersive
- design moderne et local
- animations legeres
- avis mis en avant
- contact rapide

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

---

Projet realise autour de l'univers de Grenade Auto-Ecole.
